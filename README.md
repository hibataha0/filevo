# 📁 Filevo

A cloud storage mobile application built with Flutter that allows users to upload, organize, search, and securely share files.

## 📱 Overview

Filevo is a mobile cloud storage application developed as a graduation project. It provides users with an easy and secure way to manage their files from anywhere.

## ✨ Features

- User Authentication
- File Upload & Download
- Folder Management
- File Search
- File Sharing
- File Preview
- Secure Storage
- Responsive UI

## 🛠️ Technologies Used

### Frontend
- Flutter
- Dart

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Storage
- Firebase Storage (أو AWS S3 إذا هذا المستخدم)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/hibataha0/filevo.git
```

### Install dependencies

```bash
flutter pub get
```

### Run

```bash
flutter run
```
